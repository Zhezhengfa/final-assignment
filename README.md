# 校园公共信息与数据展示中心

前端课程个人作业。围绕校园自习室与食堂信息，开发的响应式前端应用，
包含数据总览、查询筛选、ECharts 图表和 Three.js 三维校园导览。

## 一、技术栈

- HTML5 + CSS3
- Bootstrap 5（响应式布局、导航栏、卡片、徽章）
- jQuery（DOM 操作、事件绑定）
- ECharts 5（柱状图、饼图、折线图、横向条形图）
- Three.js r128（三维校园沙盘）
- 本地 JSON + fetch 异步加载

## 三、运行方法（重要：不要直接双击 html 文件）

直接用 file:// 方式打开页面时，浏览器出于安全策略会拦截 fetch 读取本地 JSON，
图表和数据将无法加载。请任选下面一种方式：

### 方式 1：VS Code Live Server（推荐）
1. 用 VS Code 打开本项目文件夹；
2. 安装 "Live Server" 插件；
3. 右键 index.html → "Open with Live Server"；
4. 浏览器自动打开 http://127.0.0.1:5500 。

### 方式 2：Python 内置服务器
在项目根目录打开命令行，执行：

    python -m http.server 8000

然后浏览器访问 http://localhost:8000

## 四、功能说明

1. 首页
   - 自习室、空闲座位、食堂、窗口数实时统计（来自 JSON）；
   - 校园公告列表；
   - Three.js 三维校园：自动旋转，可拖动旋转 / 滚轮缩放 / 平移，
     悬浮显示建筑名称，点击弹出提示。
2. 自习室查询页
   - 按楼栋、座位状态筛选；关键词搜索名称/楼栋/楼层；一键重置；
   - 堆叠柱状图：各自习室已用/空闲座位；
   - 环形饼图：各楼栋座位总量占比；
   - 图表随筛选条件联动。
3. 食堂信息页
   - 按区域筛选、菜品标签多选、关键词搜索、一键重置；
   - 多折线图：各食堂分时段人流量趋势；
   - 横向条形图：各食堂人均消费对比（按价格排序）。

## 五、常见错误与处理

| 现象 | 原因 | 解决方法 |
| --- | --- | --- |
| 数据全部显示 "--"，右上角报 fetch 错误 | 用 file:// 直接打开页面 | 改用 Live Server 或本地服务器 |
| 提示 HTTP 404 | JSON 文件路径不对或文件缺失 | 检查 data/ 目录及文件名 |
| 图表区域显示"暂无数据" | 当前筛选条件没有匹配结果 | 放宽或重置筛选条件 |
| 三维区域提示 Three.js 加载失败 | CDN 资源未加载，通常是网络问题 | 检查网络后刷新 |
| 三维区域提示不支持 WebGL | 浏览器版本过旧或未开启硬件加速 | 更换现代浏览器，开启硬件加速 |
| 页面白屏 | 脚本运行错误 | 全局错误捕获会弹窗提示，可按 F12 查看控制台 |
